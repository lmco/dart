Recommended development environment:
Python 3.9 through 3.12 (Python 3.13 is not compatible with Django 3.2.25 used by this project).
- `django==3.2.25`
- `django-bootstrap3==21.1.0`
- `python-docx>=0.8.11`

Running tests:
- Use `python manage.py test missions` from the repository root.
- Add new tests in `missions/tests.py` when fixing or extending behavior.

Contribution tips:
- Make focused changes for a single issue.
- Keep the repository's Apache 2.0 header in all new source files.
- Update documentation when behavior or setup changes.
